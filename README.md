# MarketLens 📊

**MarketLens** is a modern, responsive financial and cryptocurrency dashboard designed for real-time market tracking, currency conversions, and interactive visual analytics.

## Key Features
- **FX Rates & Currency Conversion:** Real-time exchange rates powered by Frankfurter API.
- **Crypto Market Monitoring:** Live price tracking and 24h performance metrics with dynamic fallbacks.
- **Interactive Canvas Charts:** Fast, canvas-based asset performance trends using TradingView Lightweight Charts.
- **Persistent Watchlists:** Lightweight global state management via Zustand with local storage persistence.
- **Unit Testing Suite:** Comprehensive API client and store unit tests powered by Vitest and React Testing Library.
- **Production Ready:** Optimized multi-stage Docker setup supporting standalone Next.js builds.

## Tech Stack
- **Framework:** Next.js 14 (App Router), TypeScript, Tailwind CSS
- **State & Data Fetching:** TanStack Query (React Query v5), Zustand
- **Visualization:** TradingView Lightweight Charts
- **Testing & Containerization:** Vitest, Docker
